# Tessa Pulse UI

React frontend for the Tessa Pulse MVP.

## Local development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the app at `http://localhost:5173`.

## Notes

- The frontend expects the backend API to run on `http://localhost:4000`.
- Login is simplified: a username is enough to create or access a user profile.
- The homepage uses an affinity-based personalized feed when logged in.
